# Emby同步删除（EmbySyncDel）

在 Emby 里删除电影、剧集、季或单集后，MoviePilot 自动把这部片在"下载器 → 整理 → Emby"链路上的东西一起清掉：

- 删除 MoviePilot 的整理记录
- 删除下载目录里的源文件（开启"删除源文件"时）
- 删除下载器里的种子；合集种子里还有其他影视文件时只暂停，全部删完再删种
- 同步清理 IYUU 辅种、转移做种插件留下的对应种子

适用于 MoviePilot V3（3.0.0 及以上）；MoviePilot V2 使用同仓库 `plugins.v2/embysyncdel` 的实现。

## 配置步骤

1. **Emby 添加 Webhook**（需要 Emby 4.8.0.45 及以上）：在 Emby 的通知设置里添加一个 Webhook，地址填
   `http://<MoviePilot地址>:<端口>/api/v1/webhook/?token=<MoviePilot 的 API 令牌>`，
   事件勾选媒体库的删除事件（`library.deleted`）。
2. **在 MoviePilot 里启用本插件**，各项配置：
   - 删除源文件：同时删除下载目录里的源文件并处理种子；关闭时只删整理记录
   - 发送通知：每次同步删除完成后推送一条消息
   - 清空删除记录：保存后清空插件详情页里的删除记录
   - 排除路径：命中这些路径的媒体不做同步删除，转交云盘删除类插件处理；多个路径用英文逗号分隔
   - 路径映射：见下文
3. **不要同时启用"媒体文件同步删除"插件**，两个插件会对同一个删除事件各处理一遍。

## 路径映射

插件用"媒体身份（TMDB 编号）+ 整理后的文件路径"去找整理记录。路径映射只负责把 **Emby 看到的整理后路径** 换算成 **MoviePilot 看到的整理后路径**，格式是每行一条 `Emby路径:MoviePilot路径`。

- Emby 和 MoviePilot 看到的整理后路径相同（例如都是 `/volume2/Download/transmovies/...`）：**留空**。
- 两边挂载路径不同（例如 Emby 是 `/data/movies/A.mkv`，MoviePilot 是 `/mnt/link/movies/A.mkv`）：填 `/data:/mnt/link`。

**自动检测**：插件会取最近的整理记录，按 TMDB 编号到 Emby 里找同一个文件，对比两侧路径算出映射。结论显示在配置页"路径映射"下方：路径一致时提示无需填写；需要映射时给出建议，点"填入检测结果"后保存即可生效。检测结果缓存一小时，详情页可以点"重新检测"。

源文件（下载目录）不需要映射：整理记录里本来就记着源文件路径。把整理后路径映射到下载目录，反而会一条记录都查不到。

## 处理细节

- **单集、整季**：MoviePilot V3 会按所属剧集给出媒体身份，插件据此去找整理记录。
- **不是经 MoviePilot 下载的种子**（比如用浏览器扩展直接推给下载器的）：整理记录里没有种子哈希，插件按源文件路径在下载器里找到包含该文件的种子再处理。
- **文件夹事件**：电影删除后 Emby 会再发一条空文件夹的删除事件，插件只记录"忽略"，不报错。
- **重新整理**：删除事件发生之后才整理进来的同名文件不会被删。

## 限制

- 只处理 MoviePilot 整理过的媒体（有整理记录）。直接下载进 Emby 媒体库目录、没有经过 MoviePilot 整理的文件，插件查不到记录，不会处理对应的种子。
- 源文件、整理后文件按本地路径删除，网盘等远程存储上的文件不会被删除。

## 日志

插件详情页顶部显示当前插件日志大小，"清理日志"按钮会清空插件日志并删除滚动产生的旧日志文件。每次收到删除事件都会记录类型、路径、TMDB 编号和季集号；查不到整理记录时会记录实际使用的查询条件。
